# EDI Raw File Validation Tests - Documentation

## Overview

Two comprehensive test classes are now available for testing EDI message parsing and validation with line-by-line error reporting.

---

## Test Classes

### 1. **EDIParserValidationTest.java** (Original)
**Location**: `src/test/java/javax/edi/bind/EDIParserValidationTest.java`

**Purpose**: Unit tests for validation logic with test objects

**Test Methods**:
- `testValidationWithNullFieldsLenient()` - Tests @NotNull validation
- `testValidationWithMultipleErrors()` - Tests collecting multiple errors
- `testValidationWithValidMessage()` - Tests valid message passing
- `testSummary()` - Shows implementation summary

**Example Usage**:
```java
// Lenient mode - collects all errors
EDIValidationError.ValidationResult result = 
    FieldAwareConverter.validateObjectLenient(message);

if (result.hasErrors()) {
    System.out.println(result.getDetailedErrorSummary());
}
```

## Price Validation Rules

The test uses `@Min(1)` and `@Max(100)` constraints on the `unitPrice` field:

```java
@EDISegment(tag = "PO1")
class TestPO1Segment {
    @Min(1)
    @Max(100)
    double unitPrice;  // Valid range: 1.00 to 100.00
}
```

**Violations**:
- Price < 1.00: ? Too low
- Price > 100.00: ? Too high
- Price between 1.00-100.00: ? Valid

## Running the Tests

### Run All Tests
```bash
mvn test
```

### Run Raw File Tests Only
```bash
mvn test -Dtest=EDIMessageRawFileTest
```

### Run Validation Tests Only
```bash
mvn test -Dtest=EDIParserValidationTest
```

### Run Specific Test Method
```bash
# Test reading valid EDI file
mvn test -Dtest=EDIMessageRawFileTest#testReadValidEDI850FromFile

# Test reading invalid EDI file
mvn test -Dtest=EDIMessageRawFileTest#testReadInvalidEDI850WithErrors

# Test line-by-line validation report
mvn test -Dtest=EDIMessageRawFileTest#testLineByLineValidationReport

# Test object validation with line numbers
mvn test -Dtest=EDIMessageRawFileTest#testObjectValidationWithLineNumbers
```

## Key Features

### 1. Line Number Tracking
Each error shows the exact line where it occurred:
```
Line 10 - PO1 Segment: Price 150.00 exceeds maximum
```

### 2. Segment Context
Errors include the EDI segment tag:
```
Segment Tag: PO1
Field Name : unitPrice
```

### 3. Detailed Error Information
Complete error details with:
- Line number
- Segment tag
- Field name
- Error message
- Invalid value
- Constraint details

### 4. Formatted Reports
Multiple output formats:
- Simple text summary
- Detailed box format
- Tabular report with alignment
